# Примеры реальных отчётов OsintX

Сгенерированы одной командой по цели `torvalds@gmail.com`:

```bash
osintx search "torvalds@gmail.com" --html-out examples/report_example.html \
        --json-out examples/report_example.json --md-out examples/report_example.md \
        --csv-out examples/report_example.csv
```

Файлы: `report_example.html` (наглядный отчёт), `.json`, `.md`, `.csv`.

## Что видно в примере

* **203 источника проверено**, 15 находок, 39 связей в графе сущностей.
* Движение по цепочке: `email → domain (gmail.com: MX/SPF/DMARC/поддомены) → telegram → username`,
  где локальная часть адреса автоматически проверяется как логин (через GitHub API получен
  реальный профиль с датой регистрации и репозиториями).
* **Покрытие 10.8%** — это не баг, а честность: песочница, в которой генерировался пример,
  пропускает наружу только GitHub и PyPI. Проваленные источники помечены как `error`/`blocked`
  с указанием причины, и **не** превращены в «не найдено». На машине с полным доступом в интернет
  покрытие обычно 80–95%.
* У каждой находки есть поле `доказательство` (HTTP-код, фрагмент ответа, DNS-запись) и уровень
  достоверности. Ссылки-dorks помечены как `link / confidence=low` — это не утверждения, а точки
  для ручной проверки.
