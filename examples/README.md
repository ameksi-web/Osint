# Примеры отчётов

`report_example.html` — реальный отчёт OsintX по цели `torvalds`, сгенерированный командой:

```bash
osintx search torvalds -m username --html-out examples/report_example.html
```

Обратите внимание: в отчёте видно, что из 169 проверенных источников ответил только 1
(песочница ограничивает сеть), поэтому покрытие 4.1%, а недоступные источники помечены
как error/blocked. Это и есть принцип проекта: **отказ источника не выдаётся за «не найдено»**.
На обычной машине с полным доступом в интернет покрытие будет 80–95%.
